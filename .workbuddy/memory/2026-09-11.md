## 踩坑记录

1. **SVG 图钉脉冲动画不生效的隐患**：`<circle>` 上做 `transform: scale()` 必须配 `transform-box: fill-box` + `transform-origin: center`，否则 SVG 元素会以整个 viewBox 原点缩放而飞出画面。
2. **地图 SDK 在静态构建站的陷阱**：WorkBuddy 的腾讯地图代理占位符只在运行时注入，Vite `build` 产物里是字面量，部署后必然失败。静态站优先用「自绘 SVG + URI API 跳转」组合。
