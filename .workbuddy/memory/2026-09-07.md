## 本轮新踩的坑

1. **shell 内联 node -e 做中文校验不可信**：`\\\\u` 经 bash → JS 双重转义后正则失效，会报出假的 MISS。结论：校验脚本一律写成 `.js` 文件再跑，不要内联。
2. **中文在小程序产物里是 `\uXXXX` 转义**：`grep '婚礼摄影'` 恒为 0，必须先解码再比对；且内容可能分散在 app.js / index.js 等多个分包，要全量扫描而非只看一个文件。
3. **`postcss-calc: infinity * 1rpx` 警告无害**：压缩器 CssMinimizer 会丢掉该无效声明，最终 `dist/app.wxss` 里搜不到 `infinity`，不影响运行。
