## Lumen 摄影工作室落地页

- 技术栈：Vite + React 18 + TypeScript + Tailwind 3 + framer-motion + lucide-react，工作区根目录直接建站。
- 参考 Prisma 风格（暗黑电影感 + 暖奶油色 #DEDBC8 / #E1E0CC）改造为个人摄影工作室主题：Lumen Studio。
- 三段结构：Hero（全屏视频 + 悬挂式导航 + 巨型标题带星号上标）、About（混排标题 + 滚动逐字点亮）、Features（4 卡片，含 1 个视频卡 + 3 个信息卡）。
- 关键实现：
  - `src/utils/tokenize.ts` —— 中英混合分词：英文按空格分词，中文按单字切分且不加空格（解决中文逐字动画被当成一个整体的问题）。
  - `WordsPullUp` / `WordsPullUpMultiStyle` 复用该分词器；`AnimatedLetter` 用 useScroll 逐字插值 opacity 0.2→1。
  - index.css 两个 SVG feTurbulence 噪点工具类：`.noise-overlay`(0.85/3)、`.bg-noise`(0.9/4)。
- 字体：Almarai（全局）+ Instrument Serif italic（斜体强调）+ Noto Sans SC（中文回退）。
- 构建通过：`npm run build`（tsc --noEmit + vite build），dev 端口 5173。

## 微信小程序端迁移（lumen-mp/）

用户要求「格局/布局功能要能在微信小程序上使用」，技术选型定为 **Taro 4.2 + React 18 + TS + Tailwind v4 + weapp-tailwindcss 5.x**，整站三段全量迁移（与 Web 站分开目录）。

- 栈级替换对照（这些是硬约束，不是适配层能解决的）：
  - React DOM → Taro（小程序无 DOM/BOM）
  - framer-motion → CSS keyframes + `createIntersectionObserver` + `usePageScroll`（DOM ref/WAAPI/window 全不可用）
  - lucide-react → 自绘字形图标 `src/components/Icons.tsx`（小程序无 SVG 元素）
  - Tailwind v3 → v4 + weapp-tailwindcss（转译 WXSS 兼容类名、rem→rpx）
  - `object-cover` 类 → Video 的 `objectFit="cover"` 属性
  - Google Fonts `<link>` → `wx.loadFontFace`（需自托管 + 域名白名单）
- 小程序特有坑（已处理）：
  - WXSS **不支持 `*` 通配符** → 字体只能写在 `page, view, text...` 元素选择器上靠继承
  - `gap` / `grid` 兼容性风险 → 改用 flex-wrap + 百分比宽度 + 内边距做间距
  - SVG data URI 必须 base64 编码
  - 自定义导航需手动留 `statusBarHeight`
  - 外链资源（cloudfront / higgs.ai）必须进 downloadFile 合法域名，否则真机全挂
- 构建命令：`npm run build:weapp`（Taro 不跑 tsc，配置里避免 require/@types/node 依赖）
- 逐字滚动改为整数步进 + memo，避免每个 scroll 事件触发全量 setData。
- 构建产物 `dist/` 已通过：`Compiled successfully in 34.29s`，总产物 ~368KB，app.wxss 12KB（含 Tailwind v4 工具类 + 8 个自定义动画类 + keyframes），`pages/index/index.js` 含完整组件树，`common.js` 含两个视频 URL 与三张卡片图标 URL，`project.config.json` 已就绪可直接导入微信开发者工具。
- 调试过程踩了 6 个坑（详见 `MEMORY.md`）：APPDATA 环境变量、postcss.config.js 向上泄漏、babel peerDependencies、wxss 不支持 `*`、SVG data URI 必须 base64、Tailwind v4 渐变类名差异。
